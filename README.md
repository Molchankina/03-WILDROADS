# WILDROADS

> Авторский frontend-проект о путешествиях и приключениях.

**WILDROADS** — многостраничный сайт для людей, которые хотят открывать новые места, отправляться в путешествия и получать яркие впечатления.

Проект создан с нуля в процессе изучения frontend-разработки.

---

## О проекте

Сайт объединяет несколько направлений путешествий в единой визуальной концепции.

Основной акцент сделан на:

- атмосферный визуальный дизайн;
- крупную типографику;
- фотографии природы;
- удобную навигацию;
- адаптивность;
- интерактивность;
- плавные переходы и анимации.

---

## Возможности

На сайте реализованы:

- многостраничная навигация;
- адаптивная версия для мобильных устройств;
- мобильное меню;
- интерактивные карточки маршрутов;
- формы заявок;
- выбор маршрута при оформлении заявки;
- модальные окна;
- плавная прокрутка;
- плавные переходы между страницами;
- обработка пользовательских действий с помощью JavaScript.

---

## Технологии

**HTML5 · CSS3 · JavaScript**

В проекте используются современные возможности CSS, адаптивной верстки и JavaScript для создания интерактивных элементов.

## Дизайн

WILDROADS выполнен в минималистичном природном стиле.

Визуальная концепция построена на сочетании:

**природы · свободы · путешествий · спокойствия · приключений**

Цветовая палитра, типографика, композиция и визуальные элементы подобраны как единая авторская концепция проекта.
